# Functional diversity and trophic structure of Sub-Antarctic benthos under HABs and glacial influence

This repository contains the R script used functional diversity of benthic communities in Sub-Antarctic fjords and channels, in the context of contrasting environmental stressors such as harmful algal blooms (HABs) and glacial influence.

## Repository structure
- `scripts/`: R scripts used for functional diversity analyses (mFD).
- `README.md`: Description of the repository.
- `LICENSE`: Usage license.

## Description

The analyses include:
- Functional diversity analysis based on biological and ecological traits (FRic, FEve, FDiv, FOri).

R Packages references:
